# Kişisel Harcama Takip Uygulaması
Android Studio'da Kotlin ile geliştirilmiş kişisel harcama takip uygulamasıdır.

## Özellikler
- Kullanıcı girişi (admin / 1234)
- Harcama ekleme, düzenleme, silme
- Room Database ile yerel veri saklama
- RecyclerView ile listeleme
- Gerçek zamanlı USD/EUR döviz kuru
- Kategori bazlı harcama istatistikleri

## Ekranlar
- **LoginActivity** – Giriş ekranı
- **MainActivity** – Ana ekran, harcama yönetimi
- **HistoryActivity** – Geçmiş ve istatistik ekranı

## Kullanılan Teknolojiler
- Kotlin
- Room Database
- RecyclerView & CardView
- KSP
- ExchangeRate API
